#
# 判据 = `check_skill_ref_freshness.py::unreferenced_scripts`：SKILL 带了脚本、而命令端
# （commands/agents/flows/rules/reference）无人引用 → 默认判「疑似欠账」WARN。
# 确认某脚本本就由 SKILL 自己在内部编排里调用、命令端不该出现它时，登记到本文件。
#
# ⛔ 白名单必须是**人工裁定**的结果。曾经的实现拿「SKILL 自己的文档提到过该脚本」当豁免依据，
#    而上游 SKILL 必然在自己 references 里写了自己的脚本名 ⇒ 告警永不触发；
#    某轮上游一次新增 3 个硬门脚本、命令端一个都没接，检查仍输出空列表。
#    改成显式名单后，新脚本必然冒头、必须有人看一眼「该不该接命令端」。
#
# 每条都写清为什么不用接。
