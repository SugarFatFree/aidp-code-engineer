## 四、数据清理方法

**优先（安全）— 按「测试账号 + 本次测试时间窗」精准删除**（不误删他人/真实数据）：
- 条件：`create_by = '{测试账号}' AND create_time BETWEEN '{测试开始}' AND '{测试结束}'`
- 适用：表含审计字段（create_by / create_time）。

**备选 — 按业务标记 / 主键区间删除**：表无审计字段时，按测试造数的业务标记（如名称前缀 `AUTOTEST_`）或本次新增主键区间删除，**需人工核对**。

**兜底 — 整表 TRUNCATE**：仅当该库为**独占的自动化测试专用库**（无真实 / 共享数据）时才可整表清空。

## 六、⚠️ 安全铁律

1. **仅测试环境**：本清理只在上文「二」记录的测试库执行；**生产库严禁**。
2. **执行前备份 + 确认库**：删除前确认连接的是测试库、并对涉及表快照备份。
3. **双条件优先**：优先用「测试账号 + 时间窗」双条件精准删，避免误删真实/他人数据。
4. **TRUNCATE 慎用**：仅独占测试库可整表清空。
5. **本文件随 build 归档、不可变**；后续 build 造的数据另生成新文件（`{下一 build}_数据清理.md`）。
