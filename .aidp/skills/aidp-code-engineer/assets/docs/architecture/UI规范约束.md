## 9. 响应式断点

| 断点 | 宽度范围 | 说明 |
|------|---------|------|
| xs | < 576px | 超小屏（手机竖屏） |
| sm | ≥ 576px | 小屏（手机横屏） |
| md | ≥ 768px | 中屏（平板竖屏） |
| lg | ≥ 992px | 大屏（平板横屏/小笔电） |
| xl | ≥ 1200px | 超大屏（桌面） |
| xxl | ≥ 1600px | 2K+ 屏 |
