## 1. 技术选型原则

（待团队补充或 `/sprint-design` 首次填充，例如）：
- 优先选择团队已有的公共组件
- 操作系统、数据库、中间件优先选择国产化组件
- 优先选择团队认可的安全加固版本；其他选主流通用版本
