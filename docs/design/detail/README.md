# docs/design/detail/ — 详细设计（按版本隔离）

本目录承载各版本的**详细设计 / 接口设计 / 数据库设计**，由 `/sprint-design`（通常经 `/version` 编排）生成。

## 子目录

| 子目录 | 用途 |
|--------|------|
| `{version}/` | 该版本的详细设计产出。恒有 `00_索引.md` 导航锚 + 从 `01_` 起的内容主文档（`01_详细设计.md` / `02_数据库设计.md` / `03_接口设计.md`，按实际范围；对外开放接口另立专题文档）|
| `全量/` | **正式发布**时重算的全量详细设计（覆盖式自包含交付件）。只跟最新代码走，由 `/version` 发布期生成 |

> 版本目录按需创建，不预建。命名与编号规则见约定 15；版本/用户目录约定的路径权威见 [`docs/init/06_版本与用户目录约定.md`](../../init/06_版本与用户目录约定.md)。
