## NN_研发执行计划-{开发者姓名}.md 内容

多人协作时按开发者拆分计划，从 `01_` 起顺序编号并互链索引；命名与拆分规则以 `{{AIDP_HOME}}/commands/sprint-plan.md` 及 `dev-execution-planner` SKILL 为准。个人分册包含：
- 任务清单（按 Sprint 分组）
- 执行顺序
- 时间估算
- 风险点

## 生成时机

| 命令 | 产出 |
|------|------|
| `/sprint-plan` | 生成 `00_索引.md` + 单用户 `01_研发执行计划.md`，或多用户 `NN_研发执行计划-{开发者姓名}.md` |
| `/version` | 内部调用 `/sprint-plan` |
| `/sprint-dev "<描述>"` | 默认 light，不改本目录；累进 Sprint 属 `/sprint-full "<描述>"`，其追加行到 `01_研发执行计划.md` 并刷新 `00_索引.md` 生成时间 |
| `/sprint-bugfix "<描述>"` | 默认 light，不改本目录；formal 累进同上由 `/sprint-full` 承担 |
