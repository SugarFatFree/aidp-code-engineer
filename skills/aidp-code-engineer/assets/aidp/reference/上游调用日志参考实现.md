## 骨架

```java
/**
 * 上游调用日志拦截器（约定 40）。
 * 一处接线、全局生效：请求段打完整 URL + method + 入参，响应段打 status + 出参 + 耗时，成功失败都打。
 */
public class UpstreamCallLoggingInterceptor implements ClientHttpRequestInterceptor {

    private static final Logger log = LoggerFactory.getLogger(UpstreamCallLoggingInterceptor.class);

    /** 文本体截断阈值（字节）。超出只截断、但必须标注原始长度，否则无法判断关键字段是否被截掉。 */
    private static final int MAX_BODY = 2048;

    /** 上游中文名，用于日志前缀与用户可见的错误文案（约定 23 姊妹条要求不暴露内部代号）。 */
    private final String upstreamName;

    public UpstreamCallLoggingInterceptor(String upstreamName) {
        this.upstreamName = upstreamName;
    }

    @Override
    public ClientHttpResponse intercept(HttpRequest req, byte[] body, ClientHttpRequestExecution ex)
            throws IOException {
        // 配对标识：并发下 >>> 与 <<< 会交错，没有它就无法把一次调用的两行 grep 到一起
        String traceId = Long.toHexString(ThreadLocalRandom.current().nextLong()).substring(0, 8);
        long start = System.currentTimeMillis();

        // ★ URL 必须完整（含 query string）——多环境排查第一个要确认的就是"调的哪个环境"
        log.info("[{}][{}] >>> {} {} | 入参={}",
                upstreamName, traceId, req.getMethod(), req.getURI(), summarize(req.getHeaders(), body));

        try {
            ClientHttpResponse resp = ex.execute(req, body);
            // ⚠️ 这里能安全读响应体的前提：RestTemplate 用 BufferingClientHttpRequestFactory 包装过，
            //    否则流被读空、业务侧再读就是空（见 backend.md「必踩的坑」）
            byte[] out = StreamUtils.copyToByteArray(resp.getBody());
            log.info("[{}][{}] <<< {} | status={} | 耗时={}ms | 出参={}",
                    upstreamName, traceId, req.getURI(), resp.getStatusCode(),
                    System.currentTimeMillis() - start, summarize(resp.getHeaders(), out));
            return resp;
        } catch (IOException | RuntimeException e) {
            // 失败额外带异常栈；成功路径已在上面打过 INFO，二者都不可省
            log.error("[{}][{}] <<< {} | 调用失败 | 耗时={}ms | err={}",
                    upstreamName, traceId, req.getURI(),
                    System.currentTimeMillis() - start, e.getMessage(), e);
            throw e;
        }
    }

    /** 二进制/大对象降级 + 截断 + 脱敏，三件事都在这里收口。 */
    private String summarize(HttpHeaders headers, byte[] payload) {
        if (payload == null || payload.length == 0) {
            return "<empty>";
        }
        MediaType ct = headers.getContentType();
        // ① 二进制流不打内容，只打元信息（文件名/大小/contentType）
        if (isBinary(ct)) {
            return String.format("<binary %s, %d bytes%s>", ct, payload.length,
                    headers.getContentDisposition().getFilename() == null ? ""
                            : ", filename=" + headers.getContentDisposition().getFilename());
        }
        String text = mask(new String(payload, StandardCharsets.UTF_8));
        // ② 截断必须标注原始长度
        return text.length() <= MAX_BODY ? text
                : text.substring(0, MAX_BODY) + "...(truncated, total=" + text.length() + ")";
    }

    private static boolean isBinary(MediaType ct) {
        return ct != null && (MediaType.APPLICATION_OCTET_STREAM.includes(ct)
                || MediaType.MULTIPART_FORM_DATA.includes(ct)
                || "image".equals(ct.getType()) || "video".equals(ct.getType())
                || "audio".equals(ct.getType()));
    }

    /** ③ 脱敏：黑名单命中即保留首尾各 3 位、中间 ***。黑名单应可由项目配置扩展。 */
    private static final Pattern SENSITIVE = Pattern.compile(
            "\"(password|passwd|pwd|secret|appSecret|token|accessToken|refreshToken|authorization"
            + "|apiKey|privateKey|signature|verifyCode|smsCode|captcha|idCard|idNo|bankCard|cardNo"
            + "|phone|mobile|email)\"\\s*:\\s*\"([^\"]*)\"",
            Pattern.CASE_INSENSITIVE);

    static String mask(String text) {
        Matcher m = SENSITIVE.matcher(text);
        StringBuffer sb = new StringBuffer();
        while (m.find()) {
            m.appendReplacement(sb, Matcher.quoteReplacement(
                    "\"" + m.group(1) + "\":\"" + maskValue(m.group(2)) + "\""));
        }
        m.appendTail(sb);
        return sb.toString();
    }

    static String maskValue(String v) {
        if (v == null || v.isEmpty()) {
            return v;
        }
        return v.length() <= 6 ? "***" : v.substring(0, 3) + "***" + v.substring(v.length() - 3);
    }
}
```

## 接线

```java
@Bean
public RestTemplate operationPlatformRestTemplate() {
    // ⛔ 不加 Buffering 包装 → 拦截器读完响应体后业务侧读到空，表现为"加了日志功能就坏了"
    RestTemplate rt = new RestTemplate(
            new BufferingClientHttpRequestFactory(new SimpleClientHttpRequestFactory()));
    rt.getInterceptors().add(new UpstreamCallLoggingInterceptor("订单中心"));
    return rt;
}
```

python3 {{AIDP_HOME}}/scripts/check_upstream_call_log.py --json

C1/C2 归零即满足最低要求；I1/I2/I3 为 Important，逐条看是真问题还是该加
`upstream-log-ignore: <检查号> <原因>`（**原因必须写**）。

**注意脚本的抵扣口径**：拦截器只在**同一文件内**注册时才抵扣该文件的 C1/C2，且**只抵扣 HTTP 类机制**——
对象存储 / 短信这类 SDK 直连不在 HTTP 拦截器覆盖面内，仍须在薄封装层自己打点。
