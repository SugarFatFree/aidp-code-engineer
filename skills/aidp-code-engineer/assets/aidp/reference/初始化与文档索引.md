# 初始化与文档索引

> AIDP 查阅型资料分片（非 @import、不常驻、按需 Read）；总纲见项目记忆文件 `AGENTS.md`（Claude Code 下为 `CLAUDE.md`）的「核心约定」段。

## 初始化输入文件清单

| 类型 | 路径 |
|------|------|
| AIDP 范式 | `docs/init/`（`06_版本与用户目录约定.md` 为路径权威）|
| 产品需求（项目级 PRD，兜底）| `docs/requirements/PRD-{项目名}.md` |
| 产品需求（版本级，★ 推荐）| `docs/requirements/{version}/产品提供/*.md` |
| 研发需求（生成）| `docs/requirements/{version}/研发需求/00_索引.md` + `01_研发需求.md`（多系统则 `00_索引.md` + `01_<系统>.md` / `02_<系统>.md` …；`00_索引.md` 记文件清单 + 生成时间 + 主/补充标识，约定 15）|
| 架构约束 / 技术选型 / UI 规范 | `docs/architecture/架构约束.md` / `技术选型.md` / `UI规范约束.md`（动态填充）|
| 架构设计文档（可选，项目级整体架构）| `docs/architecture/架构设计.md`（单文档）或 `docs/architecture/架构设计/`（多文档子文件夹，`00_索引.md`+`NN_*.md`）；存量任意命名兼容识别，读时全目录扫描（详见 `06_版本与用户目录约定.md` §2.1.1）|
| 第三方接口（跨版本通用全接口文档）| `docs/references/`（根）|
| 第三方对外需求（版本专属：提给第三方的需求 + 本版本对方资料）| `docs/references/{version}/`（规划期生成、强制被研发需求/详细设计引用；发布期 `/version` 整理 + 已满足加说明；详见 `06_版本与用户目录约定.md` §2.6）|
| 版本设计 | `docs/design/detail/{version}/*.md` |
| ★ 高保真原型 | `docs/prototype/{version}/mockup/{module}/`（视觉最高优先级）|
| 原型代码 | `docs/prototype/{version}/code/{module}/`（功能+交互参考）|
| 部署资产 | `docs/deployment/{version}/` 保留全量/增量 SQL 与配置文件规范，版本根 `README.md` 可作为唯一操作说明；必要时沿既有 `部署流程/部署流程.md` 与两列 `SQL执行台账.md`。数据库脚本、实际配置文件随开发/修复按需更新；文档性内容仅规划/正式发布集中整理，普通部署不为留痕改文件。细则 = `{{AIDP_HOME}}/reference/部署操作约定.md`；发布基线仍走约定 37 与 `release_baseline_check.py`。 |
| 环境配置 | `env/.env` |
| ★ 报告模板 | `{{AIDP_HOME}}/templates/reports/`（AI执行报告 + AI测试报告 + AI数据清理 + 版本测试报告 + README）|
| ★ 部署模板 | `{{AIDP_HOME}}/templates/deployment/`（`部署流程.md` + `SQL执行台账.md`；仅版本规划/正式发布按实际需要填充到 `docs/deployment/{version}/部署流程/`）|
| ★ AI 全自动报告 | `docs/reports/{version}/AI执行报告/`（autopilot 生成）+ `AI测试报告/`（aiauto-test 生成）+ `AI数据清理/`（每 build 一份数据清理文档，aiauto-test 生成、**仅 autopilot 驱动才产**，含测试环境+要清理的库+清理 SQL；测试后询问是否执行、无人值守只生成不删）+ `版本测试报告/`（/version 发布生成）；build 号 `{version}_build{N}` 详见报告模板 README |
