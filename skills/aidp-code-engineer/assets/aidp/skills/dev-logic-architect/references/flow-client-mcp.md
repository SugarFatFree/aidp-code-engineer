# 客户端 MCP 业务能力设计（条件启用 · 检查项 33 通用半场）

本文件只在调用方显式传入 `client_mcp.enabled: true`，或旧 Web 项目传入 `webmcp_enabled: true` 时加载。缺省关闭：不生成本节、不在 QR 留专项行；不得根据技术栈、浏览器驱动、Appium、项目/全局 `mcpServers` 或代码关键词自行启用。**应用业务工具**是被测产品主动向 AI 暴露的能力；**测试驱动**只负责操控客户端，驱动通过 MCP 协议连接也不能替产品证明有工具。

## 声明与冲突门

声明须明确 `客户端类型 | enabled | 应用提供能力的实现形态 | 可核对的实现来源 | 工具清单出处`。Web 的已证实实现形态为页面 WebMCP 注册；旧 `webmcp_enabled`、`webmcp_entry_symbols`、`webmcp_launch_command` 仅是 Web 适配输入，不为非 Web 创建入口。两套声明同传时客户端、enabled、实现形态逐项对账：冲突即报错并在 Module E 留待澄清，不静默覆盖；Web 专属启动参数不能作为非 Web 实现证据。

**非 Web**（小程序/移动 App/桌面）仅在已能指认**应用自有 MCP 服务或配套桥接**的实现文件/服务契约、调用主体和实例绑定方式时声明已实现；没证据写“不支持/未提供”，若产品声明开启却实现尚未取到则写“未取到 + 来源缺口”，该版本不宣称已落地。⛔ 不造一个通用对象名、统一桥接 URL、Chrome 版本门或 secure context 前提。具体通信/启动方式必须来自该端的已确认事实，而非本文件预设。

## 强制产出（一次登记，Web 不再抄第二套）

| 客户端类型 | 实现形态与文件/服务位置 | 工具名及业务作用 | 工具类别 | 输入/输出 JSON Schema 位置 | 身份与权限来源 | 写操作确认与取消 | 注册/停用生命周期 | 错误契约 | 审计日志 | 调用证据载体 |
| :- | :- | :- | :- | :- | :- | :- | :- | :- | :- | :- |
| 按本项目填写 | 须可指认 | 每工具各一行 | **只读 / 本地写 / 外发写** 三档,⛔ 无空缺、无自造档 | 输入、输出分别给可核对 Schema 或原文锚点 | 不信任调用方自报角色；后端重验归属 | 写操作列确认、取消、超时与并发 | 声明实例作用域/重连/停用拒绝 | 成功、合法空、失败分开；越权/不存在避免旁路 | 记录操作者、工具、时间、结果，敏感入参脱敏 | 注册清单与实际调用日志/JSON 的取证位置 |

⚠️ **「工具类别」不是标签,是判据**:三档决定**写操作确认门**与**错误契约强度**——只读免确认、本地写须确认、外发写须确认+幂等;该列此前只存在于 Web 专项清单,于是**非 Web 项目整条丢失**。

⚠️ **错误契约的信息泄露合并规则(端无关)**:**越权 ≡ 不存在 → 必须合并成同一条文案**——两者文案不同,等于给出一条「探测资源是否存在」的旁路;而「指名的取不到」≠「一个都没选」须**分开**。

此表供**已证实的非 Web 实现**使用,所有格子逐工具填实，不以“按业务”“沿用浏览器工具”占位。Web 项目复用 `flow-webmcp.md` 的原五列工具表及错误契约表作为同一事实来源,在其行内给输入/输出 JSON Schema 的可核对引用,并就地写身份权限/审计/调用证据的落点;**不再额外生成本十列表**。日志不落明文令牌/密钥；工具调用返回内容须遵守业务授权，写操作确认对任意调用方生效。这是通用核验口径,不是说每端存在同一个 `getTools()` 或 `invoke` API。

## 端侧分工

- **Web 已实现**：原 `flow-webmcp.md` 六项产物承载工具业务契约与页面注册、secure context、浏览器版本/启动参数、三层开关和风险登记；通用半场从同一份工具/错误表读事实,只补原表没有的 Schema/身份/审计来源说明,不复制工具表。Web 专项只核新增的页面落点/浏览器前提,不重复审通用事实。
- **非 Web 已实现**：以已证实的应用自有 MCP 服务/桥接为准，设计其进程/实例绑定、鉴权、工具注册和调用证据；不能用 Appium 或小程序自动化框架的 MCP server 代替应用服务。
- **非 Web 未实现**：标“不支持/未提供”，不新增工具表、测试入口或虚构桥接；普通 UI 仍用对应端驱动。
- **只有测试驱动可用**：例如 Chrome DevTools MCP 能点页面、Appium MCP 能操作 App，但产品没声明业务工具；`client_mcp.enabled` 仍为 false，维度 33 不触发。把驱动工具当产品工具判不通过。

以上四例是契约反例，不是对某真实项目实现状态的断言。
